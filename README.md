# SIPIAD Semillero de Investigación en Python, Inteligencia Artificial y Datos

Es un nombre bastante atractivo para estudiantes.

La ventaja es que Python funciona como puerta de entrada.

Un estudiante podría comenzar:

Python → NumPy/Pandas → visualización → ciencia de datos → Machine Learning → Deep Learning → investigación

Esto además puede conectar muy bien con tus cursos y actividades de formación.

El riesgo es que, institucionalmente, Python puede sonar más a herramienta que a campo científico. Por eso considero más sólido SI-IACC o SIADAC para presentar ante la Universidad.
